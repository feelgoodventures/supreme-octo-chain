# supreme-octo-chain
FeelGoodVentures Apps

## Privacy and support page

The static page is in `index.html`. To publish it free with GitHub Pages:

1. Push the `main` branch to GitHub.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.

After GitHub Pages finishes deploying, the page will be available at https://feelgoodventures.github.io/supreme-octo-chain/.
